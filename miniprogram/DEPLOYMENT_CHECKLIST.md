## 🔧 应急预案

### 回滚方案
**触发条件**:
- 崩溃率 > 1%
- AI 调用成功率 < 80%
- 用户投诉激增
- 发现严重 Bug

**回滚步骤**:
1. 在微信公众平台选择"版本管理"
2. 点击"回退版本"
3. 选择上一个稳定版本
4. 提交回退申请
5. 通知用户（如需要）

### 热修复方案
**适用场景**:
- 非核心功能 Bug
- UI 小问题
- 文案错误
- 配置调整

**热修复流程**:
1. 修复代码
2. 构建新版本
3. 提交审核（加急通道）
4. 审核通过后发布

### 降级方案
**降级策略**:
- AI 调用失败 → 使用固定回复（备用话术）
- 推荐服务失败 → 使用本地默认推荐
- 图片加载失败 → 使用占位图
- 网络异常 → 友好提示 + 重试按钮
