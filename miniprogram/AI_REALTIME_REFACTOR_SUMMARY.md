## 🏗️ 架构设计

### 模块化结构

```
pages/ai/
├── index.vue                    # 主页面（UI + 交互编排）
├── types/
│   └── chat.ts                  # 类型定义（6种核心类型）
├── composables/
│   ├── useAiChat.ts            # 对话核心逻辑（消息管理+AI调用）

    └── ChatMessage.vue         # 消息组件（气泡+头像+状态）
```

### 职责分离

| 模块 | 职责 | 依赖 |
|------|------|------|
| `index.vue` | UI渲染 + 用户交互 + 页面跳转 | 所有composables |
| `useAiChat` | 对话状态管理 + AI API调用 + 上下文维护 | `useAiStream`, `aiApi` |
| `useAiStream` | 流式文本展示 + 打字机动画 + 滚动控制 | 无 |
| `useAiRecommend` | 花型匹配算法 + 推荐理由生成 | 无 |
| `ChatMessage` | 单条消息渲染 + 状态展示 + 错误重试 | 无 |

## 🔑 核心功能

### 1. 真实 AI 对话

**调用链路**:
```
用户输入 → sendMessage()
         → optimizeUserInput()  [调用后端 aiApi.optimizePrompt]
         → generateAiReply()     [基于场景生成回复]
         → simulateStream()      [流式展示]
         → 更新上下文 context
```

**特性**:
- ✅ 调用后端真实 AI API (`aiApi.optimizePrompt`)
- ✅ 基于场景（送爱人/闺蜜/长辈/自己）生成个性化回复
- ✅ 维护对话上下文（最近10条消息）
- ✅ 提示词优化（用户输入 → AI优化 → 生成回复）

### 2. 流式打字机效果

**实现细节**:
```typescript
simulateStream(message, fullText, onScroll)
  1. 显示"正在输入"三点动画 (480ms 思考停顿)
  2. 逐字符显示文本 (30ms/字符)
  3. 每4个字符触发一次滚动
  4. 超时保护 (30秒)
  5. 完成时更新状态为 'done'
```

**用户体验优化**:
- 思考停顿：480ms 等待后开始输出（模拟真实思考）
- 流畅滚动：每4个字符触发滚动，避免频繁抖动
- 可中断：支持 `stopStream()` 停止输出
- 错误重试：失败时显示重试按钮

### 3. 智能推荐算法

**匹配分数计算**:
```typescript
基础分: 0.5
+ 场景匹配: +0.2~0.3  (送爱人→浪漫, 送长辈→经典)
+ 风格匹配: +0.3~0.4  (国潮纹样→国潮标签)
+ 关键词匹配: +0.2/词  (用户输入包含花型标签)
+ 精确名称: +0.5      (用户输入匹配花型名称)
────────────────────
总分: 最高1.0
```

**推荐流程**:
1. 计算每个花型的匹配分数
2. 按分数降序排序
3. 取前3个候选项
4. 生成推荐理由（基于场景+风格+花型特点）
5. 返回结果 + 置信度

**换一批逻辑**:
- 排除已展示的花型ID
- 从剩余花型中重新计算分数
- 保持推荐质量（优先高分）

## 🚀 性能优化

### 1. 流式输出优化
- **延迟控制**: 30ms/字符（可配置）
- **滚动节流**: 每4个字符滚动一次
- **超时保护**: 30秒强制终止

### 2. 状态管理优化
- **响应式状态**: 使用 Vue 3 `ref` 和 `computed`
- **最小重渲染**: 只更新变化的消息
- **上下文限制**: 历史消息最多保留10条

### 3. 用户体验优化
- **防抖处理**: 处理中禁用输入（`isProcessing`）
- **即时反馈**: 用户消息立即显示
- **错误重试**: 失败后可单独重试该消息
