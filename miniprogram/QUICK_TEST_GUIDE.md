## 🐛 如果发现问题

### 对话框位置不对
**问题：** AI对话框还在右侧
**检查：** 是否是最新构建？重新构建：
```bash
cd miniprogram/packages/app
npm run build:mp-weixin
```

### 风格还是多选
**问题：** 可以选择多个风格
**检查：** StyleGrid.vue 的 toggle 函数是否改为单选逻辑

### 跳转页面不对
**问题：** 点击按钮后跳转到错误的页面
**检查：** 
- AI助手的 `goEditor()` 应该跳转到 `/pages/upload/index`
- 详情页的 `onBuy()` 应该跳转到 `/pages/purchase/index`
- 详情页的 `onCustomize()` 应该跳转到 `/pages/upload/index`
