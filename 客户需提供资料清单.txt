□ 订单提交接口文档

    * 袜子规格（尺码、材质、数量等）

    * 收货地址

□ AI 生图服务商信息

  - API Key / Access Token
  - 调用限制（QPS、每日配额）
  - 计费方式
  
□ 生图参数要求
  - 支持的图片尺寸
  - 提示词（Prompt）格式要求
  - 风格参数配置
  - 生成数量限制
  
□ 图片存储方案
  - 生成图片的存储位置（客户服务器/第三方OSS）
  - 图片访问域名
  - CDN 配置（如需要）

□ Web 端部署
  - 域名（如：design.aihuaxing.com）
  - SSL 证书（HTTPS）

    * 服务器 IP
    * SSH 访问权限
    * 服务器配置（CPU、内存、带宽）
  
□ 小程序部署
  - 小程序平台（微信/支付宝/多端）
  - 小程序 AppID
  - 小程序 AppSecret
  - 服务器域名白名单配置
  - 业务域名配置

5. 文件存储服务
□ 图片存储方案
  - 对象存储服务（阿里云OSS/腾讯云COS/AWS S3等）
  - Bucket 名称
  - Access Key / Secret Key
  - 访问域名
  - 存储区域
  
□ 设计文件存储
  - 用户设计稿存储路径规则
  - 文件命名规范
  - 备份策略
