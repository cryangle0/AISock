# 爱花型小程序 图片素材规范说明

本文档面向运营 / 设计 / 数据准备同学，规定「爱花型 AI 袜品定制小程序」各页面所需图片的**尺寸、比例、格式与命名**，便于前期数据填充。文档基于线上小程序当前各图片展示区域的真实布局测算得出。

## 一、通用规范

### 1.1 尺寸与单位

- 小程序设计基准宽度为 750rpx（等于手机屏幕宽度）。下文「显示比例」为图片在页面中的实际显示宽高比，**比例为硬性要求**（卡片按 aspectFill 等比裁切，比例不符会被裁掉边缘）。
- 「推荐源图尺寸」为保证高分屏（2x/3x）清晰度的最小建议像素，**可按比例等比放大**，不可缩小过多。

### 1.2 格式

- 照片 / 实拍 / 插画类（不需要透明）：优先 **JPG** 或 **WEBP**（WEBP 体积更小、清晰度更好，推荐）。
- 需要透明背景的素材（模特抠图、袜子样机、AI 形象）：使用 **PNG** 或带透明通道的 **WEBP**。
- 色彩空间统一 **sRGB**；请勿使用 CMYK。

### 1.3 文件大小

- 普通卡片图：建议 ≤ 300KB。
- 全屏 / 大图（Banner、启动图）：建议 ≤ 500KB。
- 透明 PNG 较大时优先转为透明 WEBP。

### 1.4 命名

- 全英文 / 拼音小写，用「用途-描述-序号」格式，例如：`theme-dunhuang.webp`、`discover-sock-a.png`、`pattern-rose-600.jpg`。
- 切勿使用中文、空格、特殊字符。

### 1.5 安全区

- 重要主体（人物、主图案）请居中并四周预留约 8% 安全边距，避免按比例裁切时被切到。

## 二、首页（Home）

### 2.1 顶部主视觉 Banner（Hero）

首页顶部整幅主题大图，文案与装饰已可烘焙进图内。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 约 9:4（2.25:1，横图） |
| 推荐源图尺寸 | 1080 × 480 px（可等比放大） |
| 格式 | JPG / WEBP |
| 备注 | 主体居中，左侧常叠加品牌大字，注意左侧留白 |

### 2.2 主题随心订 · 主题卡封面

首页「主题随心订」三列宫格，每格一张主题封面图。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 3:2（横图） |
| 推荐源图尺寸 | 600 × 400 px |
| 格式 | JPG / WEBP |
| 备注 | 即「主题的图像」；每个主题一张，画面主体居中 |

### 2.3 案例展示 · 横滑轮播大图

首页底部 3D 横滑轮播的案例大图。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 4:5（竖图） |
| 推荐源图尺寸 | 800 × 1000 px |
| 格式 | JPG / WEBP |
| 备注 | 居中构图，会有加载渐清晰特效 |

## 三、浏览 / 发现页（Discover）

### 3.1 顶部背景大图

发现页顶部铺满状态栏到「分类 Banner」下方的背景图，上面叠主题色渐变。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 竖向 3:4 或方形（顶部可见、下部渐隐） |
| 推荐源图尺寸 | 1080 × 1440 px（或 1080 × 1080） |
| 格式 | JPG / WEBP |
| 备注 | 越往下越被主题棕色覆盖渐隐，重要内容放上半部 |

### 3.2 主题 / 分类 Banner 卡

发现页分类 Tab 下方的「全部 / 分类」主题 Banner 卡。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 约 15:8（1.87:1，横图） |
| 推荐源图尺寸 | 1040 × 560 px |
| 格式 | JPG / WEBP |
| 备注 | 底部叠分类名白字，注意下方留白 |

### 3.3 商品卡 · 模特图（左侧出血）

发现页商品记录卡左侧的全身模特照，需抠图、向上出血超出卡片。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 竖向全身，约 1:2 |
| 推荐源图尺寸 | 500 × 1000 px |
| 格式 | **PNG（透明背景）** 或透明 WEBP |
| 备注 | 必须透明背景；人物贴底、顶部可出血 |

### 3.4 商品卡 · 袜子宣传图（右侧出血，成对）

发现页商品记录卡右侧的「成对袜子」样机图，即客户所说的**商品宣传图**。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | 单只竖向约 3:5（成对并排展示） |
| 推荐源图尺寸 | 单只 360 × 600 px |
| 格式 | **PNG（透明背景）** 或透明 WEBP |
| 备注 | 必须透明背景；袜子贴底、向上出血超出卡片 |

## 四、商品花型图（核心素材）

花型主图在「发现页卡底、详情页、AI 推荐卡、购买页」多处复用，是最重要的商品素材。

| 项目 | 规格 |
| --- | --- |
| 显示比例 | **1:1 正方形** |
| 推荐源图尺寸 | 主图 800 × 800 px（最低 600 × 600） |
| 缩略图尺寸 | 400 × 400 px |
| 格式 | JPG / WEBP（无需透明） |
| 备注 | 即「商品宣传图的图像」；平铺无缝花型效果最佳 |

## 六、详情页 / 购买页

- 详情页主图、购买页缩略图均**复用第四章的花型主图（1:1）**，无需单独出图。
- 详情页「设计展示」小图：可复用花型主图或其缩略图（1:1）。
